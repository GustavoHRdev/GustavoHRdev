## 👨‍💻 Sobre Mim

Desenvolvo aplicações backend prontas para produção utilizando Java e Spring Boot, com foco em arquiteturas distribuídas, mensageria assíncrona (RabbitMQ) e consistência de dados. Profissionalmente, construo soluções de automação para ambientes industriais na **SL Alimentos**, onde código confiável e regras de negócio sólidas são fundamentais.

- 🏭 **Impacto Real:** Código rodando diariamente no monitoramento de linhas de produção e ferramentas que reduziram o tempo de análise operacional em até 80%.
- 🏦 **Arquitetura & Padrões:** Experiência prática na implementação de APIs financeiras com Outbox Pattern, processamento idempotente e filas assíncronas.
- 🧪 **Boas Práticas:** Foco em automação de testes com JUnit, MockMvc, Testcontainers e CI/CD com GitHub Actions.
